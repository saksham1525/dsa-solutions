# DSA Solutions

A log of LeetCode solutions.

## How this repo updates

Commits are pushed automatically via [LeetSync](https://github.com/3ba2ii/LeetSync), a Chrome extension that syncs LeetCode submissions to GitHub. The flow:

1. A solution is submitted on LeetCode.
2. LeetSync's browser extension picks up the submission through LeetCode's API.
3. It calls the GitHub API to create or update the corresponding file in this repo, including the submission's runtime and memory stats in the commit message.

This keeps the commit history in sync with actual submission activity on LeetCode, including performance metrics for each accepted solution.
